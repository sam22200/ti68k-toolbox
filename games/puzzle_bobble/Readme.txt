This program was written in C using TIGCC,so you don't need
any kernel,nor libraries...Just tape bobble() in the
home screen and enjoy the game !
The Game uses the great rountines from Extgraph,thanx to Thomas Nussbaumer <tict.ticalc.org> !

!! The source is (or will be soon) avaible at ticalc.org,ti89>asm>source. 


This is a classic adaptation of 'Puzzle Bubble'.It's a reflection Game,a bit like Columns,you must throw bubbles in any direction,if there is a group of more than 2 bubbles with the same colors,they disappear.The more you clean bubbles simultaneously,the more you gain points.But every ten shots,a new row of bubbles is added,and if a bubble reaches the 11 th row,you loose.    


For the moment,only the 'Record' Mode is avaible,that means you must  erase the more bubbles you can,but I will add a 'Normal' mode,with lots of levels like in the original version.And maybe a versus mode,versus the computer and perhaps a 2 players mode. 
The graphics will be surely improved,so wait for future version !





KEYS :

ESC    : Returns in Home Screen.
Arrows : Turn your cursor.
2nd    : Throw a bubble.
