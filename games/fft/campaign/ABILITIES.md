## Source catalogue and execution records

`tools/common_tables.py` builds archived `ffcj` format **FCJ3**, read in place by
`common.h`. Its 14-section directory preserves:

- All 512 eight-byte primary ability records (JP big-endian; other bytes unchanged).
- All 368 fourteen-byte default range/formula records, fourteen item formula records,
  source special tables and 128 six-byte status records.
- All 176 packed human and 48 packed monster skill sets. IDs retain bit 8; empty
  positions do not terminate a list. Human positions 0..15 are actions, 16..21 R/S/M.
- All 512 ability names and the 64 named skill sets. Unnamed sets keep their data.
- A normalized 12-byte battle record for each source ability ID, eight Charge CT
  entries and the two reviewed battle labels `Charge +1` / `Charge +2`.

The enabled set covers the existing encounters: Accumulate, Dash, Throw Stone,
Heal, Wish, Potion, Antidote, Eye Drop, Echo Grass, Phoenix Down, Stasis Sword,
Night Sword, Speed Break, Magic Break and Charge +1/+2. `formula.inc` dispatches
through source formula IDs. The previous Orbonne weapon/stat-break adaptations
are preserved; this checkpoint does not claim new original-game fidelity for them.
Other execution records have `kind=255` and are rejected before use.

Source locations come from local `sources/fft_decomp/target/main.yaml`,
`include/fft/data.h`, `main_ability_get_id_from_skillset.c` and
`main_ability_calculate_pointers_and_type.c`. The binary check compares the local
US disc records. Retail data and generated captures stay local.

## Battle, save and module boundaries

`AbId` and `LearnBits` are now 16 bits in the campaign. Menus, previews, pending
Charge actions and AI candidates retain source IDs. `known()` scans all sixteen
sparse source positions and skips actions whose evaluator is unavailable.
A learned but unavailable action survives save/load. `FSV2` stays compatible.
The bag has fourteen source item slots; descriptors map chapter inventory into them.

Descriptors are **FCD2**. The generator converts legacy extraction records into
28-byte source unit definitions inside the descriptor. Separate draw masks preserve
old RNG calls/order, so widening a skill set does not reroll the existing encounters.
Legacy compact tables remain extraction inputs only; the active battle does not
read their ability/set adapters.

`MOD_FORMULA` is the sixth image in `ffbm`. The same evaluator source is compiled
locally into `MOD_AI`: an AI candidate never overwrites its executing overlay.
Core callers reuse that evaluator when AI is already resident; otherwise they
load the small formula image. This avoids copying AI out and back for a preview.
Encounter generation now shares `MOD_SAVE`; `unit_stats` stays resident because
level-ups must not load the save module. No new assembler was written.

Management uses **FMG2**, with 32-byte job records instead of 120. Names, ability
lists and JP costs come from `ffcj`; the world map accepts the same management bank.
Update programs, descriptors and banks together: old format versions are rejected.
